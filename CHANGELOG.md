# Changelog

This file records user-facing changes for published app versions. A release entry is
added only when the `bump-publish` skill prepares a version update; there is no rolling
Unreleased section.

Entries are ordered newest first and use `## [<version>] - <YYYY-MM-DD>`, followed by
relevant `### Added`, `### Changed`, and `### Fixed` sections. Omit empty sections.
